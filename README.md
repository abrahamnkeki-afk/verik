# Verik

Technical hiring through proof of work. Candidates fix one real debugging task, get interviewed on their own code, and receive a shareable ProofScore profile.

## Run locally

    ./setup.sh
    pnpm dev

Open http://localhost:3000.

## Deploy

1. Push to GitHub.
2. Import the repo in Vercel.
3. Add the variables from .env.example under Settings, Environment Variables.
